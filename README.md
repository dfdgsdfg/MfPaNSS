## 이 자료에 대하여

이 저장소는 유튜브 채널/디스코드 커뮤니티 **수학의 즐거움(Enjoying Math)** 의 채널/커뮤니티 지기 "geonheecho"가 이끈 강의 **직장인과 문과생을 위한 수학교실**의 자료를 정리한 것입니다. 참여자들은 (주로 온라인으로) 정기적으로 모여 토의, 학습, 상호 퀴즈 점검등 각 기수별 1년여의 가까운 시간동안 함께 수학의 즐거움을 누린 결과물을 공유하고 있습니다.

제공된 자료는 계속해서 이어지고 있는 학습 공동체의 스냅숏으로써, 실제로 기록으로 제공될수 없는, 사람과 사람이 목소리와 표정으로 수학에 대해 함께 즐거움을 나누는 모든 과정 아래에서의 부분적인 기록입니다. 원본 강의와 그 활동을 대체할 수 없으며, 검수되지 않은 상태로 AI에 의해 재구성되어 강의자와 참여자의 의도, 맥락, 정확성과 수학적 정합이 모두 손상되었을 수 있음을 알립니다.

### 구성
- **원본 노트** — [Lecture notes of Mathematics for Professionals and Non Stem Students (Google Drive)](https://drive.google.com/file/d/1JCb7mX5I5r37BxibXv8_5VKoMwTrhZV_/view?usp=share_link) · "geonheecho"에 의해 최초 작성된 강의 노트
- **전사본** (`NN-*/…md`) — 강의노트 PDF를 OCR·재구성한 문서. AI로 전사되어 오류가 있을수 있음
- **영상 정리노트** (`…-0K-season-LL.md`) — 각 기수(시즌) 중 공개된 영상을 정리한 노트. AI로 정리되어 오류가 있을수 있음
- **Anki** (`… anki-0K-season-LL.tsv`) — 계산 드릴 문제에 대한 플래시 카드
- **페르소나** (`agents/personas/*.persona.md`) — 저장소에 정리된 자료를 활용하는 AI 페르소나 프롬프트

### 한계·면책
- 이 자료는 커뮤니티 공식 자료가 아닌, 공개된 강의와 강의 노트를 토대로 개인적인 작성으로, 커뮤니티의 요청에 따라 삭제, 수정 될 수 있습니다.
- 전사본은 손글씨 **OCR·재구성**, 영상 정리노트는 **자동자막(ASR) 기반**이며 AI를 통해 정리되었기에 의도, 맥락, 정확성과 수학적 정합이 모두 손상되었을 수 있습니다.
- 모두 **개인 학습용 정리**입니다. **멤버십 전용 영상의 파생물(영상·자막·노트)** 은 포함되거나 제공되고 있지 않습니다.
- 본 자료는 위 학습 공동체의 작업에 기댄 것이며, 강의자와 참여자에 의해 검수되지 않았으며, 남아 있는 오류·오타·누락은 모두 정리자의 책임입니다.

## 기타

이 저장소의 md(전사본·정리노트·Anki)를 지식으로, `agents/personas/`의 프롬프트를 지침으로 활용 가능합니다.

- 튜터: [`math-tutor.persona.md`](agents/personas/math-tutor.persona.md)
- 퀴즈 진행자:[`quiz-master.persona.md`](agents/personas/quiz-master.persona.md)

### Claude (claude.ai / Claude Code)
- **claude.ai** — Project를 만들고 *지침(Instructions)* 에 페르소나 md를 붙여넣은 뒤, 전사본·정리노트·Anki `.md`들을 *Project knowledge* 로 추가합니다. 이후 그 Project 안에서 대화하면 됩니다.
- **Claude Code (CLI)** — 이 레포에서 열면 끝입니다. "1강 가르쳐줘" → `lecture-tutor`, "퀴즈 내줘 / 계산 훈련 시켜줘" → `lecture-quiz-master` 스킬이 자동으로 페르소나를 입습니다. 수동 주입도 가능: `claude --append-system-prompt "$(cat agents/personas/math-tutor.persona.md)"`.

### GPT (ChatGPT)
- **Custom GPT** — GPT 만들기에서 *Instructions* 에 페르소나를 붙이고, *Knowledge* 에 단원 전사본·정리노트·Anki `.md`(문제/해답 분리본)를 업로드합니다.
- **Projects** — 프로젝트의 *지침* 에 페르소나, *파일* 에 md를 추가해도 동일하게 동작합니다. (Python 계산 시범은 Code Interpreter가 켜져 있어야 합니다.)

### Gemini / AI Studio
- **Gemini Gems** — 새 Gem의 *지침* 에 페르소나를 붙이고, *지식(파일)* 에 md를 추가합니다.
- **Google AI Studio** — *System instructions* 에 페르소나를 붙이고, 프롬프트에 md 파일을 첨부(또는 Drive 연결)해 사용합니다. Code execution을 켜면 계산 시범까지 됩니다.

### 주기적으로 퀴즈, 혹은 강의 인트로 받기
복습은 주기성이 생명이라, 플랫폼의 예약 기능에 페르소나를 얹어 두면 좋습니다. 배달 모드는 두 가지입니다 — **퀴즈**(퀴즈마스터가 드릴 문제를 내고, 답하면 채점)와 **강의 인트로**(짧게 처음 시작안내 후 다음 질문을 함께 제시).

- **ChatGPT Tasks(예약 작업)** — 페르소나를 넣어 둔 Project/GPT 대화에서 예약합니다. 퀴즈: "매일 아침 9시에 직문수 드릴 1문제를 내고, 내가 답하면 채점해 줘". 강의 인트로: "매일 아침 9시에 직문수 노트에서 주제 하나를 골라 5분 분량 인트로 강의를 보내 줘 — 끝에 이어갈 질문 3개와 함께". 매일 알림으로 도착합니다.
- **ChatGPT Pulse** — (Pro·모바일) 대화·메모리 기반의 매일 브리핑입니다. 페르소나와 꾸준히 대화하고 Pulse 큐레이션에 "매일 직문수 복습 퀴즈 한 문제" 또는 "오늘의 직문수 강의 인트로 하나"를 요청해 두면 아침 카드로 떠오릅니다.
- **Gemini 예약 작업(Scheduled actions)** — "매일 오전 8시에 행렬 고유치 문제 1개를 내 줘"(퀴즈), "매일 오전 8시에 직문수 다음 단원의 인트로를 짧게 들려줘"(강의)처럼 Gemini에 직접 예약합니다.
- **Claude Code `/schedule`** — 이 레포에서 `/schedule`로 클라우드 정기 에이전트를 만듭니다. 퀴즈: "매일 quiz-master 페르소나로 Anki 덱에서 5문제 라운드를 뽑아 `quiz-today.md`로 저장". 강의 인트로: "매일 math-tutor 페르소나로 `index.md` 순서를 따라 다음 강의의 인트로(개괄 + 계산 예시 + 다음 질문)를 `lecture-today.md`로 저장". 세션 안에서 가볍게는 `/loop`도 됩니다.
