5. 음함수와 그래디언트의 직교성

레벨셋 위에서 움직이면 F 값은 늘 0이라 접방향 d 에 대한 방향도함수 가 0입니다. 그래서 그래디언트 ∇F 는 레벨셋에 수직이고, 접선은 그것과 직교합니다. 점 P 를 곡선 위에서 끌어 보거나 슬라이더로 레벨 c 를 바꿔 다른 레벨셋으로 옮겨 보세요.

P
∇F = (2x, 2y)
접방향 d = (-y, x)
⟨∇F, d⟩
dy/dx = -Fx/Fy


접방향은 Fx·dx + Fy·dy = 0 를 만족하고, 거기서 dy/dx = -Fx/Fy 가 나옵니다. 수직 접선(곡선 위·아래 끝)에서는 Fy=0 이라 dy/dx 가 발산합니다.
